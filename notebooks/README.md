# Kaggle notebooks

Thin launchers: clone the repo, install, check SHA-256 gates, run the repo's scripts, write results to `/kaggle/working`. Each one fails loudly
(raises, so the kernel ends as an ERROR) rather than reporting a truncated run as complete.

| Notebook | Purpose |
|---|---|
| `kaggle_pretrain.ipynb` | Phase 3 pretraining (resumable across sessions) |
| `kaggle_sft.ipynb` | Phase 4 SFT |
| `kaggle_dpo.ipynb` | Phase 4 DPO (learning-rate sweep, two final seeds, evaluation) |
| `kaggle_bench.ipynb` | Phase 5 inference benchmarks on a T4 |
| `kaggle_sae_probe.ipynb`, `kaggle_sae_full.ipynb` | Phase 6 SAE: 10-epoch probe, then the 192-epoch layer-4 run |
| `kaggle_steering.ipynb` | Phase 6 steering (`MODE = "probe"` timing check or `"full"`); generated by `analysis/gen_steering_nb.py` |

They need the private Kaggle datasets named in each notebook (weights, shards, SAE), which are not public. The `analysis/check_*_notebook.py` scripts run the
cells in a local Jupyter kernel for a pre-flight check.
